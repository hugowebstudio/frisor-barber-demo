# Frisör & Barber – hemsidedemo

Det här är en fristående demohemsida skapad av Hugo Web Studio för frisörsalonger och barberare.

## Publicera med GitHub Pages
1. Öppna repositoryts **Settings**.
2. Välj **Pages** i sidomenyn.
3. Under **Build and deployment**, välj **Deploy from a branch**.
4. Välj branch **main** och mapp **/(root)**.
5. Klicka **Save**.

När GitHub har publicerat sidan blir adressen:
https://hugowebstudio.github.io/frisor-barber-demo/

## Vad demon innehåller
- Dam-, herr- och barnklippning med exempelpriser
- Behandlingar, salongsinformation och bildgalleri
- Exempel på personalpresentationer
- Exempel på hårvårdsprodukter och priser
- Kontaktuppgifter, öppettider och bokningssektion

All text, priser, bilder, personaluppgifter, kontaktuppgifter och bokningslänkar är exempel. De anpassas eller tas bort efter kundens önskemål. Bokningsknappen är inte kopplad till ett riktigt bokningssystem.

## Bilder
Demonsidan använder bildfiler från Hugo Web Studios publika bildbibliotek via GitHub. Du behöver inte ladda upp bilder för att visa demon. I ett kundprojekt byts bilderna till kundens egna bilder eller andra godkända bilder.
